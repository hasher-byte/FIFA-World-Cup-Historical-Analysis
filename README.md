# ⚽ FIFA-World-Cup-Historical-Analysis

The project uses a historical international football dataset and filters the relevant FIFA World Cup records for analysis.


## 📌 Project Overview

This project analyzes historical FIFA World Cup data to identify trends and patterns in match results, goals, goal scorers, penalty shootouts, and team performance.

The analysis was performed using Python and focuses on the complete data analytics workflow:

**Data Loading → Data Cleaning → Data Manipulation → Exploratory Data Analysis → Visualization → Insights**


## 📊 Dataset

The dataset was obtained from Kaggle:

**International Football Results from 1872 to 2026 — Mart Jürisoo**

🔗 [Kaggle Dataset](https://www.kaggle.com/martj42/international-football-results-from-1872-to-2017?select=former_names.csv)

**Dataset Files**

| File | Description |
|---|---|
| `results.csv` | Match results and scores |
| `goalscorers.csv` | Goal-scoring information |
| `shootouts.csv` | Penalty shootout information |
| `former_names.csv` | Historical team-name information |

## 📈 Analysis

Using all 4 dataset files, this project analyzes historical FIFA World Cup data to identify trends and patterns in matches, goals, team performance, and penalty shootouts.

**Key Areas**
- Match Analysis — match outcomes, win/draw patterns, scorelines, and team performance
- Team Performance — World Cup winners, total wins, and performance across tournaments
- Goal Analysis — top goal scorers, team goals, scoring patterns, and goal timings
- Penalty Shootouts — shootout frequency, winning teams, and home vs away performance
- Historical Analysis — changes in team names and historical naming patterns


## 🔍 Key Insights

- Identified the most successful teams based on FIFA World Cup titles and match wins.
- Analyzed the most common match scorelines and overall match outcome patterns.
- Identified top goal scorers and teams with the highest number of goals.
- Examined goal-scoring patterns throughout matches, including the distribution of goals by match minute.
- Analyzed the frequency and outcomes of penalty shootouts and compared home vs away team performance.
- Identified historical changes in national team names and examined patterns in team name changes over time.
